# Embedded default Web / 内嵌默认前端

This directory embeds the May Monitor Web revision recorded in the Server root `frontend.lock.json`. It is not a separate public theme installation directory.

此目录使用固定的 May Monitor Web 构建，不从旧 Komari 页面或浮动分支下载资源。构建、打包和测试步骤统一见 [Build](../../docs/BUILD.md)；公开 May Status 主题通过独立的固定静态主题流程启用，不覆盖这里的管理／初始化界面。

`defaultTheme/dist.tar.zst` 与 `defaultTheme/komari-theme.json` 来自同一已核对的 Web 提交。保留技术文件名和许可证，不为了品牌修改协议合同。
