# May Monitor 只读监测接入

监控支线 M3的 Server RC3 源码在已认证快照增加可选 `server_instance_id`。该值来自受管安装的随机身份，不是凭据；schema 保持 1。未配置身份时省略该字段，原只读指标可用，但不能通过 Deploy 的来源比对和试迁移验收。配套候选尚未发布。

本接口是 `v0.1.0-rc.1` 之后的源码功能，尚未随该预发布版发行。它供 May Deploy 等受信任原生控制端读取明确授权节点的最新指标，不授予管理员、Agent、远程命令、文件或数据库管理权限，也不替代原有管理 API。

配套候选为 Server `0.1.0-rc.2`；Deploy 监控支线 M2已增加摘要／范围／期限的显式配置和独立生命周期，见[部署契约](DEPLOY-LIFECYCLE.zh-CN.md)。新版本尚未发布，RC1 不能据此视为已有该接口。

## 授权与配置

默认关闭。维护者必须同时提供下列进程环境变量：

```text
MAY_MONITOR_READ_TOKEN_SHA256=<专用只读令牌的64位十六进制SHA-256>
MAY_MONITOR_READ_CLIENT_UUIDS=<节点UUID>,<另一个节点UUID>
MAY_MONITOR_READ_EXPIRES_AT=<RFC3339格式的UTC到期时间>
```

最多 100 个不同的、非空的标准小写 UUID；不接受通配范围。到期时间必须在当前时间之后、90 天以内，缺失、过期、无效或范围不明确时均拒绝。权限由进程环境决定，不能通过普通 Web 设置更改。

令牌格式为 `may_read_` 加 32 字节密码学随机数据的无填充 base64url 编码。Deploy 的「监测 → 配置只读连接」可以生成令牌、绑定节点并预览上述配置，默认有效期为 30 天。原始令牌只保存在控制端的加密私人归档；服务端只需摘要。不要把原始令牌复制到普通管理员 Key、Agent Token、订阅 URL、命令行参数或公开日志。

按照当前实例已验收的服务管理方式，将以上变量放入单独的服务环境文件，限制文件访问权限，并在维护窗口重启对应服务使环境生效。本功能不假设某个安装目录、服务单元名或原 Komari 布局，不自动修改它们。反向代理应只向受信任调用方开放所需入口，保留 HTTPS，并转发 `Authorization` 请求头。

同一配置目前对应一份只读凭据和一组节点。需要不同调用方独立凭据／范围时，应另行设计凭据生命周期，不能通过复用完整管理员 Key 扩权。

## 协议 v1

```http
GET /api/integration/v1/snapshot HTTP/1.1
Authorization: Bearer <may_read_专用令牌>
Accept: application/json
```

不接受查询参数、请求正文或非 GET 方法。该精确路径在私有站点中使用独立鉴权，不放行整个路径前缀。普通管理员会话、管理员 API Key、匿名访问或 Agent Token 不能代替专用只读授权。

响应字段：

| 字段 | 口径 |
| --- | --- |
| `schema_version` | 当前为整数 `1` |
| `server_version` | 当前服务端版本 |
| `captured_at` | 本次快照生成的 UTC 时间 |
| `nodes[].uuid` | 同时属于授权范围和当前已注册列表的节点 UUID |
| `nodes[].online` | 当前 WebSocket 连接或未过期保活状态 |
| `nodes[].report_at` | 最近样本时间，无样本为 `null` |
| `nodes[].metrics` | 可用指标对象，否则为 `null` |
| `metrics.cpu_percent` | 0 至 100 的有限 CPU 百分比 |
| `metrics.memory_used`／`memory_total` | 字节，使用量不超过正的总量 |
| `metrics.upload_per_sec`／`download_per_sec` | 非负字节每秒 |
| `metrics.upload_total`／`download_total` | Agent 最近上报的非负累计字节 |

没有样本和非法样本不填成零。上报时间是否新鲜由调用方结合当前时间判断；在线状态不保证某条代理线路可用，也不代表最近指标一定新鲜。累计计数不替代账单或监测历史统计。

未知／已删除节点不返回，但不暴露其他节点。没有返回绑定 UUID 时，调用方应显示“核对授权或注册状态”，不能据此直接宣布离线。响应不包含节点 Token、名称、IP、私人备注、用户、配置、计费或任务数据。

接口不写入监测数据库，不复制全部节点的历史，只查询已授权 UUID 并复制最多 100 个最新样本。响应使用 `Cache-Control: no-store`；调用方也不能缓存到 Service Worker 或公开代理缓存。

## 续期与撤销

1. 续期：维护者核对仍需访问的节点，更新服务环境的到期时间并重启服务。重新生成预览文本本身不改变服务器。
2. 轮换：控制端生成新的专用令牌，在服务端更新摘要／范围／到期时间并重启，然后保存控制端连接。旧令牌应返回 401。
3. 撤销：移除摘要或所有只读授权环境设置并重启服务，确认旧凭据返回 401。删除控制端加密文件只影响本机，不等于撤销服务端授权。
4. 恢复：授权配置无效时保持关闭；不要回退成公开站点、普通管理员 Key 或匿名访问。服务端当前没有凭据自动续期与 HTTP 管理入口。

每个请求重新检查配置、范围与有效期，没有跨请求的令牌授权缓存。环境变量属于进程环境，修改外部配置文件后必须按服务管理流程重启，不能把测试里的动态环境修改当作生产热更新。

## 验证边界

源码包含独立凭据表格测试和真实路由的临时 SQLite／合成指标回归，覆盖私有站点、范围、敏感字段、非法数值、过期／撤销、非 GET、查询参数及不能进入管理、Agent 和 RPC 路径。相关包执行竞争检测。

Deploy 使用正常 TLS、只在回环允许 HTTP、不使用 Cookie 或自动重定向，完整读取时限 10 秒、响应 256 KiB、节点 100 个。生产服务账号、反向代理、真实网络、长时间资源消耗、安装迁移与回退尚需单独验收。现有远程控制、扩展等默认关闭策略不因启用只读接口而改变。

监控支线 M2已在一次性 Debian 12／13 中完成实际专用服务账号、安装、RC1→RC2 升级、真实 Agent、备份、恢复、取消和重启验证，并记录短时资源数据。公网 HTTPS、生产迁移、长期资源及旧数据导入仍不在本地验证结论内。
